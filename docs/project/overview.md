# Классификатор изображений

**Классификатор изображений** — небольшой веб-сервис, который определяет категорию
объекта на загруженной пользователем фотографии.

Пользователь загружает изображение (JPEG или PNG), сервис передаёт его ML-модели
классификации изображений и возвращает наиболее вероятные категории объекта
с оценкой уверенности модели. Результаты сохраняются, поэтому к ним можно вернуться позже.

Если модель не уверена в ответе (уверенность ниже порогового значения), сервис
сообщает об этом и предлагает пользователю проверить результат самостоятельно.

## Основные пользователи

- **пользователь** — загружает фотографии и получает категорию объекта;
- **администратор сервиса** — следит за качеством классификации, просматривает
  результаты и список поддерживаемых категорий.

## Основные функции

- загрузка изображения;
- определение категории объекта на изображении (top-N категорий с уверенностью);
- просмотр результата классификации по его идентификатору;
- просмотр списка категорий, которые умеет распознавать модель.
