# Классификатор изображений

Документация учебного ИИ-проекта «Классификатор изображений» в подходе Docs as Code.

Сервис определяет категорию объекта на загруженной фотографии с помощью
модели Vision Transformer (`google/vit-base-patch16-224`).

## О проекте
Документация хранится в Git и создаётся с помощью MkDocs. Диаграммы описаны
в Mermaid, API — в OpenAPI 3.0.

## Разделы

- [Проект](project/overview.md) — описание, требования (User Stories, Use Case), UML-диаграммы;
- [API](api/index.md) — описание API и спецификация OpenAPI / Swagger UI;
- [ML](ml/model-card.md) — Model Card, Data Sheet, риски и ограничения.
