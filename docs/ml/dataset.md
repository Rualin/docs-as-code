# Data Sheet

Модель `google/vit-base-patch16-224` предобучалась на ImageNet-21k и дообучалась на ImageNet-1k.
Для описания выбран основной датасет — **ImageNet-1k**, так как именно его 1000 классов
модель возвращает в нашем сервисе.

## Общая информация

**Название датасета:**
ImageNet-1k (ImageNet Large Scale Visual Recognition Challenge 2012, ILSVRC 2012).

**Источник:**
<https://huggingface.co/datasets/ILSVRC/imagenet-1k> (доступ по запросу), официальный сайт <https://www.image-net.org/>

**Назначение:**
Обучение и оценка моделей классификации изображений; стандартный бенчмарк компьютерного зрения.

## Состав данных

**Объём:**

| Часть | Количество изображений |
|-------|------------------------|
| train | 1 281 167 |
| validation | 50 000 |
| test | 100 000 (метки не опубликованы) |

Общий размер — около 167 ГБ. 1000 классов.

**Тип данных:**
Цветные фотографии (JPEG) различного разрешения с одной меткой класса на изображение.

**Основные поля / признаки:**

- `image` — изображение;
- `label` — индекс класса от 0 до 999 (например, `281` — «tabby, tabby cat»).

Классы организованы по иерархии WordNet: каждый класс соответствует «синсету» —
понятию, описанному одним или несколькими словами. Названия классов на английском языке.

## Получение данных

Изображения собраны из интернета через поисковые системы по запросам, соответствующим
синсетам WordNet. Разметка выполнена с привлечением краудсорсинга (в карточке на Hugging Face —
`annotations_creators: crowdsourced`); исполнители подтверждали, что на изображении присутствует
объект нужного класса.

## Предобработка

В самом датасете: изображения сохранены в исходном разрешении, предобработка авторами датасета
не указана.

При обучении модели (по карточке модели): изображения масштабировались до 224×224 и нормализовались
по каналам RGB со средним (0,5; 0,5; 0,5) и стандартным отклонением (0,5; 0,5; 0,5). Детали
аугментаций описаны в репозитории `google-research/vision_transformer` (input_pipeline.py).

## Ограничения

- лицензия «other»: датасет доступен для некоммерческих исследовательских и образовательных
  целей по условиям ImageNet; коммерческое использование изображений требует отдельной проверки;
- набор классов неравномерен по тематике: много пород собак и видов животных, при этом
  нет многих бытовых категорий, актуальных для пользователей;
- изображения взяты из интернета и могут отражать географические и культурные перекосы
  (преимущественно англоязычные источники) — точная оценка авторами не указана;
- в разметке встречаются ошибки и неоднозначные изображения с несколькими объектами
  (поэтому был создан пересмотренный набор меток ImageNet ReaL);
- метки тестовой части не опубликованы, для оценки обычно используется validation.

## Использование в проекте

- Классы ImageNet-1k — это и есть справочник категорий сервиса (`GET /categories`).
- Validation-часть можно использовать для проверки модели после развёртывания и подбора
  порога `lowConfidence`.
- Для оценки на реальных данных сервиса потребуется собственная тестовая выборка пользовательских
  фото, так как они могут отличаться от изображений ImageNet по качеству и тематике.
