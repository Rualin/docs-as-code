# Риски и ограничения

Анализ относится к модели [`google/vit-base-patch16-224`](model-card.md) и датасету
[ImageNet-1k](dataset.md). Наличие bias не утверждается: доступной информации недостаточно
для его количественной оценки, поэтому риски сформулированы как потенциальные и требуют проверки.

## Потенциальный bias

### 1. Географический и культурный перекос данных

**Риск:**
Изображения ImageNet собирались из интернета, преимущественно по англоязычным запросам.
Существует потенциальный риск, что объекты из разных стран и культур (одежда, еда, жилища,
бытовые предметы) представлены неравномерно.

**Возможное последствие:**
Для пользователей из России и других регионов качество классификации привычных им объектов
может быть ниже, чем для объектов, типичных для западных стран.

**Что можно сделать:**
Собрать небольшую тестовую выборку фотографий, характерных для целевой аудитории сервиса,
и сравнить точность с результатами на ImageNet validation; при заметном падении — дообучить модель.

### 2. Несоответствие набора классов задачам пользователей

**Риск:**
Классы ImageNet-1k распределены неравномерно по тематике (например, около 120 пород собак),
при этом многих повседневных категорий нет. Модель всегда выбирает один из 1000 классов.

**Возможное последствие:**
Объект «неизвестной» категории будет уверенно отнесён к похожему, но неверному классу;
по одним темам ответы будут чрезмерно детальными, по другим — систематически ошибочными.

**Что можно сделать:**
Показывать пользователю top-5 категорий и флаг низкой уверенности; собирать статистику
жалоб на неверные ответы; при необходимости сгруппировать классы в укрупнённые категории
или дообучить модель на нужном наборе классов.

## Этические риски

### 1. Чрезмерное доверие к ответу ИИ

**Риск:**
Пользователь воспринимает категорию, предложенную моделью, как гарантированно правильную —
например, при определении вида гриба, ягоды или растения.

**Последствие:**
Ошибочная классификация может привести к опасному решению (например, употребление
ядовитого гриба).

**Способ снижения риска:**
Явно сообщать, что результат сформирован ИИ и может быть ошибочным; показывать уверенность
и флаг `lowConfidence`; в правилах использования указать, что сервис не предназначен
для решений, связанных со здоровьем и безопасностью.

### 2. Обработка персональных данных на фотографиях

**Риск:**
На загружаемых фото могут оказаться люди, документы, номера автомобилей, геометки в EXIF.
Сервис сохраняет изображения и результаты.

**Последствие:**
Утечка или использование фото без согласия пользователя нарушает приватность и требования
законодательства о персональных данных (152-ФЗ).

**Способ снижения риска:**
Удалять EXIF-метаданные при загрузке; хранить изображения ограниченное время или не хранить
вообще (сохранять только результат); получать согласие пользователя на обработку;
ограничить доступ к результатам ролью администратора.

### 3. Использование модели не по назначению

**Риск:**
Сервис могут попытаться использовать для оценки людей на фото (внешность, возраст,
«тип» человека) или для медицинских выводов.

**Последствие:**
Дискриминационные или ложные выводы о людях; вред здоровью при самодиагностике.

**Способ снижения риска:**
Зафиксировать ограничения в [Model Card](model-card.md) и пользовательском соглашении;
не возвращать результаты для классов, относящихся к людям, без пометки; принимать важные
решения только с участием человека.
