# Model Card

## Общая информация

**Название модели:**
Vision Transformer (base-sized model), `google/vit-base-patch16-224` (ViT-B/16, вход 224×224).

**Источник:**
Hugging Face Hub — <https://huggingface.co/google/vit-base-patch16-224>

**Автор / организация:**
Google Research (Dosovitskiy и др.). Веса сконвертированы из репозитория timm (Ross Wightman).
Карточку модели на Hugging Face написала команда Hugging Face, а не авторы модели.

**Задача модели:**
Классификация изображений (image classification) на 1000 классов ImageNet-1k (ILSVRC 2012).

**Язык:**
Модель работает с изображениями, а не с текстом. Названия классов — на английском языке.

**Лицензия:**
Apache-2.0.

**Архитектура:**
Трансформер-энкодер (BERT-подобный). Изображение разбивается на патчи 16×16 пикселей,
которые линейно проецируются в эмбеддинги; для классификации используется токен `[CLS]`.
Предобучена на ImageNet-21k (14 млн изображений, 21 843 класса), дообучена на ImageNet-1k
(около 1 млн изображений, 1000 классов), обе стадии — в разрешении 224×224.

## Использование в проекте

Модель — ML-компонент сервиса «Классификатор изображений» (см. [описание проекта](../project/overview.md)).

1. Пользователь загружает фото через endpoint `POST /classifications` ([API](../api/index.md)).
2. Сервис проверяет файл, приводит изображение к 224×224 RGB и нормализует его так же,
   как при обучении модели (`ViTImageProcessor`).
3. Модель возвращает логиты для 1000 классов; сервис применяет softmax и выбирает top-5 категорий.
4. Если вероятность лучшей категории меньше 0,5, результат помечается флагом `lowConfidence`.
5. Результат сохраняется вместе с версией модели (`modelVersion`) и доступен через
   `GET /classifications/{id}`. Список классов модели отдаётся через `GET /categories`.

Взаимодействие компонентов показано на [диаграмме последовательности](../project/diagrams.md).

## Входные данные

Одно RGB-изображение. Перед подачей в модель изображение масштабируется до 224×224 пикселей
и нормализуется по каналам RGB со средним (0,5; 0,5; 0,5) и стандартным отклонением (0,5; 0,5; 0,5).
В проекте принимаются файлы JPEG и PNG размером до 10 МБ.

## Выходные данные

Вектор из 1000 логитов — по одному на каждый класс ImageNet-1k. Индекс класса переводится
в название через `model.config.id2label` (например, `281 → "tabby, tabby cat"`).
Сервис преобразует логиты в вероятности (softmax) и возвращает top-N категорий с уверенностью.

## Метрики качества

В карточке модели метрики для данного чекпойнта (224×224) **не указаны авторами модели** —
карточка ссылается на таблицы 2 и 5 статьи.

По данным статьи (Table 5): ViT-B/16, предобученная на ImageNet-21k, после дообучения
достигает **83,97 % top-1 accuracy на ImageNet** и 88,35 % на ImageNet ReaL. Эти значения
получены при дообучении в разрешении **384×384**, поэтому для используемой версии 224×224
точность может быть ниже. Карточка также отмечает, что лучшие результаты получаются
при более высоком разрешении.

## Ограничения

Ограничения, указанные в источниках:

- модель распознаёт только 1000 фиксированных классов ImageNet-1k; объект другой категории
  всё равно будет отнесён к одному из этих классов;
- для используемого разрешения 224×224 качество ниже, чем при 384×384 (по данным карточки и статьи);
- в статье отмечено, что ViT обладает меньшим индуктивным смещением, чем свёрточные сети,
  и хорошо работает только при предобучении на больших датасетах — дообучение на маленьком
  собственном наборе данных может дать слабый результат.

Потенциальные ограничения для нашего проекта (собственный анализ, не из источника):

- **Потенциальное ограничение для нашего проекта:** модель возвращает одну категорию для всего
  изображения; если на фото несколько объектов, будет определён лишь один из них.
- **Потенциальное ограничение для нашего проекта:** качество может снижаться на тёмных, размытых,
  сильно сжатых фото и при необычном ракурсе — нужно проверить на реальных пользовательских фото.
- **Потенциальное ограничение для нашего проекта:** уверенность (softmax) не является
  откалиброванной вероятностью правильного ответа; порог 0,5 нужно подобрать на тестовой выборке.

## Не рекомендуется использовать

- для медицинской диагностики (снимки, дерматология и т. п.);
- для распознавания и идентификации людей, определения пола, возраста, национальности;
- для принятия юридически значимых решений или решений о безопасности без проверки человеком;
- для детектирования нескольких объектов и их положения (это задача object detection, а не классификации);
- для узкоспециализированных изображений (спутниковые, микроскопия, промышленный брак) без дообучения.
