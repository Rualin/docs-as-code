# API

API предоставляет доступ к функциям ИИ-сервиса «Классификатор изображений»:
загрузке фотографии, определению категории объекта и получению сохранённых результатов.

Базовый адрес (условный): `https://example.com/api/v1`

## Основные операции

| Метод | Endpoint | Назначение |
|-------|----------|------------|
| `POST` | `/classifications` | загрузить изображение и выполнить классификацию |
| `GET` | `/classifications/{id}` | получить сохранённый результат классификации |
| `GET` | `/categories` | получить список категорий, которые распознаёт модель |
| `GET` | `/categories/{categoryId}` | получить категорию по идентификатору |

## Пример: классификация изображения

Запрос (`multipart/form-data`):

```bash
curl -X POST https://example.com/api/v1/classifications \
  -F "image=@cat.jpg" \
  -F "topK=2"
```

Ответ `201 Created`:

```json
{
  "id": 123,
  "predictions": [
    { "rank": 1, "category": { "id": 281, "label": "tabby, tabby cat" }, "confidence": 0.94 },
    { "rank": 2, "category": { "id": 282, "label": "tiger cat" }, "confidence": 0.04 }
  ],
  "lowConfidence": false,
  "modelVersion": "google/vit-base-patch16-224",
  "processingTimeMs": 182,
  "createdAt": "2026-11-05T12:30:00Z"
}
```

## Ошибки

Все ошибки возвращаются в едином формате (схема `Error`):

```json
{ "code": "UNSUPPORTED_FORMAT", "message": "Only JPEG and PNG images are supported" }
```

| Код | Когда возникает |
|-----|-----------------|
| `400` | не передан файл или параметры вне допустимого диапазона |
| `404` | результат или категория не найдены |
| `413` | размер файла больше 10 МБ |
| `415` | формат файла не JPEG и не PNG |
| `422` | файл повреждён и не читается как изображение |
| `500` | внутренняя ошибка сервиса |
| `503` | ML-модель временно недоступна |

## Проверка документации API

Проверка выполнена по Swagger UI для основного endpoint `POST /classifications`:

| Вопрос | Ответ по документации |
|--------|-----------------------|
| Какой HTTP-метод используется? | `POST` |
| Какие данные нужно передать? | файл `image` в `multipart/form-data`, необязательный `topK` |
| Какие поля обязательны? | только `image` |
| Что возвращается при успехе? | `201` и объект `ClassificationResult`: id, список `predictions`, `lowConfidence`, `modelVersion`, время обработки |
| Какие ошибки возможны? | `400`, `413`, `415`, `422`, `500`, `503` — с кодом и сообщением в схеме `Error` |
