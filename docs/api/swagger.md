# Swagger UI

Интерактивное представление спецификации [`openapi.yaml`](openapi.yaml).
Для отображения нужен доступ в интернет (Swagger UI загружается с CDN).
Реального сервера нет, поэтому кнопка «Try it out» не вернёт ответ.

[Открыть Swagger UI на отдельной странице](swagger.html)

<iframe src="../swagger.html" style="width:100%; height:900px; border:1px solid #e1e4e5;"></iframe>

Спецификацию также можно проверить в [Swagger Editor](https://editor.swagger.io/),
вставив туда содержимое `openapi.yaml`.
